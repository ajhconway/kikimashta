# Pack 1 comprehension review

All 232 questions were checked for target-word dependence. Masking the target must make the answer indeterminate. Each target-only counterfactual keeps the question, choices and other facts fixed and has a different entailed answer. Both target-focus and contextual-detail questions must meet this rule.

Structural checks verify the replacement and different key, not Japanese entailment. Original and counterfactual answer keys require independent semantic review. The existing non-copying and beginner-language requirements still apply. All revised text remains pending; original accepted media and progress are preserved.

## 一つ · simple · ja-ctx-wk1-simple-hitotsu-01-target

**Decision:** retained-after-review. **Focus:** target. **Operation:** quantity-meaning.

**Before:** 皿の上にりんごが一つあります。 → りんごは何個ありますか。

**After:** 皿の上にりんごが一つあります。 → りんごは何個ありますか。

**Choices:** １個 ✓ / ２個 / ３個 / ４個

**Meaning required:** 一つ (ひとつ) gives a quantity of one; the matching 個 form is １個 (いっこ).

**Copying check:** All written quantities use Arabic numerals and the different 個 counter; the heard 一つ (ひとつ) is absent from every option. Selecting 1 requires knowing its quantity, not copying its sound.

**Target required:** The target is the only statement of this group's quantity. If it is masked, neither the named object, its location, an all-eaten action nor a different group's count determines the answer. The spoken counter must be understood as a number.

**Change only:** 一つ → 二つ

**Counterfactual sentence:** 皿の上にりんごが二つあります。

**Answer changes:** １個 → ２個

**Counterfactual evidence:** The original 一つ (ひとつ) means 1 items in the requested object/owner group. Replacing it with 二つ (ふたつ) changes that same quantity to 2, so the entailed answer becomes ２個. All other scene facts stay fixed.

## 一つ · simple · ja-ctx-wk1-simple-hitotsu-01-detail

**Before:** 皿の上にりんごが一つあります。 → 皿はどこにありますか。

**Copying check:** Every substantive answer uses numeric 個 forms absent from the sentence. The correct one/many category cannot be selected by repeating the object or its location.

**Counterfactual sentence:** 皿の上にりんごが二つあります。

**Answer changes:** １個だけです → １個より多いです

**Counterfactual evidence:** The original quantity 1 is one; the natural replacement 二つ makes it 2, which is greater than one. The one/many answer changes while object and location stay unchanged.
